# Braty Engine add-ons: net, tls, http, websocket

> **For agentic workers:** implement task by task, in order (each task depends on the one before).
> Steps use checkbox (`- [ ]`) syntax. One task = one agent = one or more small commits.

**Goal:** optional add-ons that ship in the repository and the SDK but are compiled and linked
only when a build asks for them; the first four are raw sockets (SDL3_net), TLS streams, an
HTTP/HTTPS client and a WebSocket client. Release 0.2.0.

**Architecture:** each add-on is a folder `addons/<name>/` that builds one static library
`braty_<name>` (alias `braty::<name>`) on top of `braty::braty`. A build selects add-ons with the
cache variable `BRATY_ADDONS`; a resolver (`cmake/BratyAddons.cmake`) reads each add-on's declared
dependencies, pulls them in, orders them and stops on a cycle. At run time an add-on keeps its
state in the engine through a small core registry (`br_addon_add` / `br_addon_get`) and is switched
on by the game calling `br_<name>_register(e)`. Dependency chain: `net <- tls <- http <- websocket`.

**Tech stack:** C11, SDL3 3.4.20, SDL3_net `release-3.2.0` (zlib licence, FetchContent), Mbed TLS
`v3.6.8` LTS (Apache-2.0, FetchContent from the release tarball: the git tag needs a submodule),
Mozilla CA bundle `cacert.pem` (MPL-2.0, committed).

**Spec:** the owner's request (2026-11-22): add-ons come with the engine, are not in the core, are
not compiled unless selected, may depend on each other without cycles; implement SDL3 network,
http/https and websocket; teach `AGENTS.md`; release 0.2.0. `tls` is a fourth add-on because
`https://` and `wss://` need it and SDL3_net has none.

## Global Constraints

- Everything in `AGENTS.md` "Code rules" applies to add-on code (C11, naming, zero warnings with
  `-Wall -Wextra -Wpedantic` and `/W4`, no platform `#ifdef`s, errors return + log, every public
  function has a one-line doc comment, no heap allocation per frame, `// ponytail:` on shortcuts).
- **The core stays as it is.** `braty` (engine/src) gains only the add-on registry of Task 1. It
  never includes an add-on header, never links an add-on, and builds and passes its tests with
  `BRATY_ADDONS` empty (the default).
- **One relaxation, add-ons only:** an add-on may bring third-party code beyond SDL3 + the C
  standard library, fetched or vendored by its own `CMakeLists.txt`, listed with its licence in
  `third_party/README.md`. Add-on sources still use no platform headers.
- Everything is non-blocking and main-thread: start, keep a handle `{index, generation}` (zero =
  none), poll its state from a system. No callbacks, no threads of the add-on's own (the CA
  bundle parse may use `br_job`). Stale and zero handles are safe to pass everywhere.
- Fixed tables sized by a `BR_<ADDON>_MAX_*` constant; buffers grow once and are reused. Steady
  traffic on an open connection allocates nothing.
- **Hostile data:** everything read from the network is untrusted. Every length is checked
  against a limit before use; over the limit fails that connection with a logged reason, never
  crashes, hangs or allocates without bound. Limits go in README "Limits".
- Timeouts use real time (`SDL_GetTicksNS`), not game time (a paused game still times out).
- Tests run without the internet: loopback (127.0.0.1) inside the test process, a distinct fixed
  port per test program (47801 and up). Parsers and codecs are pure functions with their own
  tests that open no socket. Tests live in `addons/<name>/tests/test_*.c`.
- Local builds: `cmake --preset windows-gcc -DBRATY_ADDONS=all`, build and run **only your own
  test targets** (`ctest --preset windows-gcc -R <name>`). The full suite runs on GitHub: push,
  `gh run watch --exit-status`. Git: `git add` specific paths, subjects `addons: ...`, `net: ...`.
- Commit trailer: `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. A server that sends a huge or never-ending header / body / frame: the request or socket fails
   at the limit with a clear error; memory stays bounded. (Tasks 4, 5: parser tests.)
2. `https://` to a host with a wrong, expired, self-signed or wrong-name certificate: FAILED with
   a readable `br_tls_error`, never silently connected. (Task 3: loopback TLS tests.)
3. The peer closes mid-message (half a header, half a chunk, half a frame): FAILED / CLOSED, no
   hang, no partial body reported as DONE. (Tasks 2, 4, 5.)
4. A game that enables `websocket` only: `net`, `tls`, `http` are built and linked without being
   named, and `br_websocket_register` registers them. (Task 1 resolver test, Task 5.)
5. Handles used after close / release, or from before the peer vanished: every call is a logged
   no-op or returns the "none" value. (Each add-on's test.)

## File structure

```
cmake/BratyAddons.cmake            resolver + braty_addon() helper (Task 1)
addons/CMakeLists.txt              resolves BRATY_ADDONS, add_subdirectory in dependency order
addons/<name>/addon.cmake          set(BRATY_ADDON_DEPENDS <names>)  - nothing else
addons/<name>/CMakeLists.txt       third-party fetch + one braty_addon(...) call
addons/<name>/include/braty/br_<name>.h      public API
addons/<name>/src/*.c, *_internal.h
addons/<name>/tests/test_*.c       CTest programs (label `addons`)
addons/<name>/examples/*.c         built, not run by CTest (they need the internet)
docs/agents/addons.md              the system; docs/agents/{net,tls,http,websocket}.md
tests/addon_fixtures/              fake add-on trees for the resolver test
```

### Task 2: `net` - TCP and UDP on SDL3_net

**Files:** `addons/net/{addon.cmake,CMakeLists.txt,include/braty/br_net.h,src/br_net.c,tests/test_net.c}`,
`third_party/README.md` (row: SDL3_net, release-3.2.0, zlib).

`addon.cmake`: no dependencies. `CMakeLists.txt`: `find_package(SDL3_net CONFIG QUIET)`, else
FetchContent `https://github.com/libsdl-org/SDL_net.git` tag `release-3.2.0`, static, no samples,
installed with the SDK when `BRATY_INSTALL`. Read SDL3_net's header before designing the bodies.

**Produces** (`br_net.h`; all handles `{uint32_t index, generation}`):

```c
#define BR_NET_MAX_SOCKETS 64
#define BR_NET_MAX_SERVERS 8
#define BR_NET_MAX_UDP 8
typedef enum br_net_state { BR_NET_CLOSED, BR_NET_CONNECTING, BR_NET_OPEN, BR_NET_FAILED } br_net_state;

bool          br_net_register(br_engine *e);                 /* idempotent; false = SDL_net init failed */
br_net_socket br_net_connect(br_engine *e, const char *host, uint16_t port);   /* resolves, then connects */
br_net_state  br_net_socket_state(br_engine *e, br_net_socket s);  /* CLOSED for zero / stale handles */
bool          br_net_send(br_engine *e, br_net_socket s, const void *data, size_t size); /* queued; false unless OPEN */
size_t        br_net_send_pending(br_engine *e, br_net_socket s);  /* bytes queued, not yet on the wire */
int           br_net_receive(br_engine *e, br_net_socket s, void *buffer, int capacity); /* bytes, 0 = none now, -1 = closed or failed */
void          br_net_close(br_engine *e, br_net_socket s);   /* frees the slot; queued data is sent first where SDL_net allows */
br_net_server br_net_listen(br_engine *e, uint16_t port);    /* all interfaces; zero handle + log on failure */
br_net_socket br_net_accept(br_engine *e, br_net_server server);  /* zero handle when nobody waits */
void          br_net_server_close(br_engine *e, br_net_server server);
```

UDP: `br_net_udp_open(e, port)` (0 = any), `br_net_udp_send`, `br_net_udp_receive`,
`br_net_udp_close`, plus `br_net_address` (`br_net_resolve`, `br_net_address_state`,
`br_net_address_get_string`, `br_net_address_release`) because a datagram needs a resolved
address. The implementer fixes those signatures against SDL3_net's `NET_Address` reference counts;
the contract is: non-blocking, the sender's address and port come back from receive, no heap
allocation per datagram, a datagram larger than `capacity` is dropped and logged.

A system `net.update` (INPUT phase, early) advances CONNECTING sockets (resolve -> connect ->
OPEN / FAILED) and notices peers that went away.

### Task 3: `tls` - a byte stream, plain or TLS

**Files:** `addons/tls/{addon.cmake,CMakeLists.txt,include/braty/br_tls.h,src/br_tls.c,certs/cacert.pem,tests/test_tls.c}`,
`tests/data/tls/` (test CA, server certificate + key, a second untrusted CA; generated once with
`openssl`, valid until at least 2099, the commands in a `README.md` there), `third_party/README.md`.

`addon.cmake`: depends on `net`. Mbed TLS 3.6.8 via FetchContent from the release tarball
(`mbedtls-3.6.8.tar.bz2` on the GitHub release, with `URL_HASH`), programs and tests off, static,
default configuration (`// ponytail:` a trimmed config would shrink the library). `cacert.pem`
(curl.se/ca/cacert.pem, date noted in `third_party/README.md`) becomes a C array at configure time
(CMake `file(READ ... HEX)` into the build directory), so nothing is read from disk at run time.

**Produces** (`br_tls.h`):

```c
#define BR_TLS_MAX_STREAMS 32
bool          br_tls_register(br_engine *e);          /* registers net first; idempotent */
/* A stream to host:port; secure = TLS 1.2+ with certificate and host-name verification and SNI. */
br_tls_stream br_tls_open(br_engine *e, const char *host, uint16_t port, bool secure);
br_net_state  br_tls_state(br_engine *e, br_tls_stream s);     /* OPEN only after the handshake verified */
bool          br_tls_send(br_engine *e, br_tls_stream s, const void *data, size_t size);
int           br_tls_receive(br_engine *e, br_tls_stream s, void *buffer, int capacity);  /* as br_net_receive */
void          br_tls_close(br_engine *e, br_tls_stream s);     /* sends close_notify when secure */
const char   *br_tls_error(br_engine *e, br_tls_stream s);     /* why it FAILED ("" otherwise); valid until close */
/* Replaces the built-in root certificates (PEM text is copied): your own server's CA, pinning. */
bool          br_tls_set_ca_pem(br_engine *e, const char *pem, size_t size);
/* Verification on (default) or off; off logs a warning on every secure open. Development only. */
void          br_tls_set_verify(br_engine *e, bool on);
/* Cryptographic random bytes (Mbed TLS CTR-DRBG). */
bool          br_tls_random(br_engine *e, void *out, size_t size);
/* SHA-1 of data (WebSocket handshake; not for security). */
void          br_tls_sha1(const void *data, size_t size, uint8_t out[20]);
/* Base64 text of data, NUL-terminated; returns its length, 0 when capacity is too small. */
size_t        br_tls_base64_encode(const void *data, size_t size, char *out, size_t capacity);
```

Mbed TLS talks to the socket through BIO callbacks over `br_net_send` / `br_net_receive`
(`WANT_READ` / `WANT_WRITE` when nothing is there); system `tls.update` (INPUT, after
`net.update`) drives handshakes. The built-in roots are parsed once, lazily, in a `br_job`
(count 1) started by the first secure open; secure streams stay CONNECTING until it is done.
`// ponytail:` the handshake's public-key maths runs on the main thread (a few ms per connection).

**Produces** (`br_http.h`):

```c
#define BR_HTTP_MAX_REQUESTS 16            /* in flight; one more fails (logged) */
#define BR_HTTP_MAX_HEADER_BYTES (64 * 1024)
#define BR_HTTP_DEFAULT_MAX_BODY (16 * 1024 * 1024)
#define BR_HTTP_DEFAULT_TIMEOUT 30.0f
#define BR_HTTP_MAX_REDIRECTS 5
typedef enum br_http_state { BR_HTTP_NONE, BR_HTTP_PENDING, BR_HTTP_DONE, BR_HTTP_FAILED } br_http_state;

typedef struct br_http_url { bool secure; char host[256]; uint16_t port; char path[2048]; } br_http_url;
/* Splits http:// https:// ws:// wss:// URLs (default ports 80 / 443, path "/" when missing). */
bool br_http_url_parse(const char *url, br_http_url *out);

typedef struct br_http_desc {
    const char *method;         /* NULL = "GET" */
    const char *url;
    const char *headers;        /* "Name: value\r\n" lines, NULL = none */
    const void *body;           /* NULL = none */
    size_t      body_size;
    float       timeout;        /* seconds for the whole request, 0 = BR_HTTP_DEFAULT_TIMEOUT */
    size_t      max_body;       /* response bytes accepted, 0 = BR_HTTP_DEFAULT_MAX_BODY */
} br_http_desc;

bool            br_http_register(br_engine *e);                         /* registers tls (and net) */
br_http_request br_http_send(br_engine *e, const br_http_desc *desc);   /* copies everything it needs */
br_http_request br_http_get(br_engine *e, const char *url);
br_http_state   br_http_request_state(br_engine *e, br_http_request r); /* DONE = a complete response, any status */
int             br_http_status(br_engine *e, br_http_request r);        /* 200, 404...; 0 until DONE */
const char     *br_http_header(br_engine *e, br_http_request r, const char *name);  /* case-insensitive, NULL if absent */
const void     *br_http_body(br_engine *e, br_http_request r, size_t *size);        /* NUL-terminated; valid until release */
float           br_http_progress(br_engine *e, br_http_request r);      /* body bytes / Content-Length, 0 when unknown */
const char     *br_http_error(br_engine *e, br_http_request r);         /* why it FAILED */
void            br_http_release(br_engine *e, br_http_request r);       /* frees the response; cancels a pending one */
```

to 5 (303 and, for POST, 301 / 302 become GET; never from https to http). `// ponytail:` one
connection per request (no keep-alive), no gzip, no proxy, no cookies, no HTTP/2.
`br_http_internal.h` exposes the pure parser (`br_http_response_parser` fed bytes incrementally,
the request writer, the chunk decoder) for the parse test and for `websocket`.

### Task 5: `websocket` - RFC 6455 client

**Files:** `addons/websocket/{addon.cmake,CMakeLists.txt,include/braty/br_websocket.h,src/br_websocket.c,src/br_websocket_frame.c,src/br_websocket_internal.h,tests/test_websocket_frame.c,tests/test_websocket.c,examples/websocket_echo.c}`.

`addon.cmake`: depends on `http` (URL parser, response parser; `tls` and `net` come with it).

**Produces** (`br_websocket.h`):

```c
#define BR_WEBSOCKET_MAX 8
#define BR_WEBSOCKET_DEFAULT_MAX_MESSAGE (16 * 1024 * 1024)
typedef enum br_websocket_state {
    BR_WEBSOCKET_CLOSED, BR_WEBSOCKET_CONNECTING, BR_WEBSOCKET_OPEN, BR_WEBSOCKET_CLOSING, BR_WEBSOCKET_FAILED
} br_websocket_state;
typedef struct br_websocket_message { const void *data; size_t size; bool text; } br_websocket_message;

bool               br_websocket_register(br_engine *e);     /* registers http, tls, net */
/* ws:// or wss://; protocols = "chat, v2" or NULL; headers as br_http_desc.headers or NULL. */
br_websocket       br_websocket_open(br_engine *e, const char *url, const char *protocols, const char *headers);
br_websocket_state br_websocket_socket_state(br_engine *e, br_websocket ws);
bool               br_websocket_send_text(br_engine *e, br_websocket ws, const char *text);
bool               br_websocket_send_binary(br_engine *e, br_websocket ws, const void *data, size_t size);
/* The next whole message, false when none waits. data is NUL-terminated and valid until the next
 * br_websocket_receive on this socket. */
bool               br_websocket_receive(br_engine *e, br_websocket ws, br_websocket_message *out);
void               br_websocket_set_max_message(br_engine *e, br_websocket ws, size_t bytes);
/* Starts the closing handshake (code 1000 = normal); the slot is freed by br_websocket_release. */
void               br_websocket_close(br_engine *e, br_websocket ws, uint16_t code, const char *reason);
uint16_t           br_websocket_close_code(br_engine *e, br_websocket ws);   /* the peer's code, 1006 = dropped */
const char        *br_websocket_error(br_engine *e, br_websocket ws);
void               br_websocket_release(br_engine *e, br_websocket ws);
```

Behaviour: handshake with a random 16-byte key (`br_tls_random`), `Sec-WebSocket-Accept` checked
(`br_tls_sha1` + base64), a status other than 101 fails with the status in the error. Client
frames masked with a fresh random mask. Fragmented messages reassembled; control frames between
fragments handled; ping answered with pong; text messages must be valid UTF-8 (else close 1007);
a message over the limit closes with 1009; protocol errors close with 1002. No extensions
(`// ponytail:` no permessage-deflate). The frame codec (`br_websocket_internal.h`) is pure.
