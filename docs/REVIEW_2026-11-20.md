# Full code review, 2026-11-20: summary for the owner

What was reviewed, what was fixed and how it is tested, what is still open and why, and the
larger changes that were deliberately not made. Plan: `docs/plans/2026-11-20-engine-review.md`.
The eight reports (`build/review/R1.md` .. `R8.md`) are local working files under `build/`
(gitignored); every fix below is a commit on `main` and is named here.

## How it ran

1. **Review.** Eight reviewers read the whole engine in slices (table below), ran repro programs
   and wrote one report each: findings ranked S1 (crash, corruption, hang, wrong output in normal
   use), S2 (wrong in a reachable edge case, leak, race), S3 (API / design, performance trap,
   missing test, wrong doc), S4 (nit, at most ten per report).
2. **Fix.** One fix branch per slice (`fix-r1` .. `fix-r8`), merged into `main`. Each accepted
   finding was first reproduced by a test that failed, then fixed.
3. **Final pass** (this document's commit series): small leftovers the fix agents reported but
   did not own, and the documentation pass.

State after the final pass: zero warnings, `ctest --preset windows-gcc` 62 / 62 (35 test
programs, 24 examples run headless, 2 play-test scripts, 1 golden run of 27 images), the
golden run passes on Direct3D 12 (Vulkan differs in 10 of 27 cases, informative only),
`tools/check_getting_started.py` builds and runs all 15 steps.

### R1 Foundation (merge `a381c52`)

Fixed, with the test that covers it:

- Game state freed before node destroy listeners ran at exit: nodes are destroyed before any
  game shutdown callback (`b2e024e`; `test_app` `test_teardown_order`).
- `br_array` size arithmetic wrapped (heap corruption, endless reserve): checked, plus
  `br_u32_mul_ok` / `br_size_mul_ok` helpers (`e26a3e1`; `test_core` `test_array_overflow`).
- Saves named after the raw window title (a `:` broke every save): org + app identity,
  sanitised, and atomic writes through `<path>.tmp` (`bf1c65e`; `test_core` / `test_app`
  `test_save_identity`).
- A degenerate triangle contained every point on its line; projections of zero extents gave
  NaN (`38ccabc`; `test_math` `test_degenerate`).
- Negative / NaN ticker speed, `br_system_add` returning void, linear scan of retired system
  names (`0a626a0`; `test_core` `test_system_churn`).
- Stale arena stack markers and pool double frees accepted (`d720d5b`; `test_arena`).
- Two vsync APIs: `br_gpu_set_vsync` removed (`dfc4017`; no test, an API removal).
- Late transient allocations and out-of-range texture uploads accepted silently; a readback
  inside a frame now warns (`8c190d3`; new `test_gpu`: `test_transient`, `test_textures`,
  `test_samplers`).
- App lifecycle (R8's S2, implemented here): pause when inactive, lifecycle callbacks, unscaled
  delta (`edc58fc`; `test_app` `test_lifecycle_state`, `test_unscaled_delta`,
  `test_pause_when_inactive`, `test_deterministic_input_filter`).

Open: `br_pipeline_desc` cannot express depth bias, fill mode, several colour targets or a
stencil reference (S3, a design extension, deferred). One-off uploads during RENDER still land
before the frame's commands (documented, readback warns).

### R2 2D scene and drawing (merge `fc82115`)

Fixed:

- `br_node_destroy` outside a step re-entered the flush (double free); recursive tree walks
  overflowed the stack at ~7000 levels; destroying many children was O(n^2); mask and render-layer
  cycles were accepted (`f368803`; `test_node` `test_reentrant_destroy`, `test_deep_chain`,
  `test_mass_destroy`, `test_mask_and_layer_cycles`).
- A stencil mask containing a node masked by it recursed forever; scissor masks vanished and
  advanced blends read the wrong backdrop in offset views; a stencil mask with alpha 0 wrote no
  stencil; `cache_as_texture` baked the node's alpha / tint (`a52caa3`; new
  `examples/render_views_demo.c` and its golden, `e57788a`).
- Component field offsets not checked against the component size (`36de610`;
  `test_components`).
- Render texture sizes converted from NaN / negative floats; wrong-type loads kept their
  reference (`132327a`; `test_texture`).
- Stale docs (culling mask, particle scissor masks, sprites example filters).

Open (S3): effects and render-to-texture inside a canvas3d-captured subtree record passes into
the captured list (use texture mode for filtered canvas content); `cache_as_texture` in two
views of different zoom re-renders twice per frame. Neither has a commit.

### R3 Assets and data (merge `9b1aeb5`)

Fixed:

- A prefab containing itself recursed until the stack overflowed; asset collection re-read every
  prefab occurrence; counts and ints from data were cast unchecked; `br_data_texture` read an
  uninitialised path; hot reload freed assets before the old nodes were flushed; game.json
  string / int edge cases (`7bb2eb9`; new `test_hostile_data`: `test_prefab_cycles`,
  `test_ranges`, `test_long_names`, `test_malformed_files`; `test_scene_file`
  `test_reload_in_frame`). New readers `br_data_get_count` / `br_data_get_int_range`.
- `{a,b}` pattern expansion was exponential (now at most 16 names); any `.json` with "frames"
  and "meta" was claimed by the spritesheet loader (now a structural test and fallback to the
  next loader); a loader loading its own path overwrote the cache entry; a failed async load
  confused asset groups; DDS / KTX mip counts and sizes trusted (`ac60e77`; `test_assets`
  `test_loader_choice`, `test_asset_group` `test_failure_then_other_owner`,
  `test_hostile_data` `test_brace_patterns`).
- `br_system_add_for_scene` with an existing name later removed that unrelated system; a
  switch whose target was unloaded during the fade unloaded every scene (`cc9e335`;
  `test_scene` `test_scoped_name_collision`, `test_switch_target_unloaded`).

Open (S3, no commit): `br_asset_group_load` during a running async load cancels `on_done`
(`br_asset_group.c`, `g->async = false`); a capture unref during a scene build can cancel a
record taken by someone else (`br_assets_capture_unref`).

### R4 Graphics and text (merge `c4d542b`; the fix report is appended to R4.md)

Fixed:

- Truncated / malformed TTF crashed the engine: table offsets checked before stb_truetype
  (`a5edc2b`; `test_text` `test_bad_fonts`).
- A dashed stroke on a long segment never finished; no caps on points, polygon sides, star
  points; `line_to` after `close_path`; pixel lines drawn after every triangle; SVG numbers
  accepted nan / inf / hex (`f146fae`; `test_graphics` `test_bad_input`, `test_close_path`,
  `test_svg_numbers`; `graphics_demo` golden updated after looking at it).
- Text nodes kept freed fonts after uninstall / reinstall / unload (`313330a`; `test_text`
  `test_font_lifetime`).
- One huge glyph grew the atlas to 4096; JSON stroke / blur made seconds of work per glyph;
  glyphs that did not fit were rasterised every frame; style numbers unclamped (`deb54cb`;
  `test_text` `test_atlas`). New `br_text_prepare`.
- Split text dropped pieces of 1024 bytes and more (`8a415d0`; `test_text`).
- `.fnt` page textures never released, distanceRange <= 0 accepted, every `.xml` claimed
  (`50b5dc8`; `test_text` `test_fnt_assets`).
- MTSDF pages premultiplied on upload eroded glyphs (`16eb8d3`; verified by screenshots then;
  pinned by the `sdf_fonts_demo` golden in the final pass).

Deferred: the per-frame cost of text (a cmap lookup per glyph per layer per pass, all quads
re-emitted every frame): the per-node quad cache below.

### R5 Interaction and tooling (merge `7578549`)

Fixed:

- Play-test "view/node" labels over 63 characters overflowed a stack buffer; unknown argument
  names were ignored; the log ring was written from threads without a lock; recordings kept
  SDL's synthetic touch / pen mouse events. Adds the `window` command and dotted component
  names in paths (`f9833df`; `test_playtest` `test_hardening`, `test_log_threads`,
  `test_record_synthetic_mouse`).
- Audio: INF speed hung the mixer, NaN start / volume / pan, sounds never finished without a
  playback device (`d09802c`; `test_audio` `test_bad_floats`, `test_no_device_game_clock`).
- Gamepads: injected pad ids shared after assign, a release after disconnect re-created the pad,
  a pad removed while held never released, triggers used the stick dead zone (`a0166b4`;
  `test_input` `test_gamepad_hotplug`). New trigger dead zone (default 0.05), join / leave
  edges, `br_input_inject_gamepad_connect` (a family for injected pads).
- Debug: key releases swallowed while a field was edited; no way to switch F1 / F2 off; log
  lines read without the lock (`7f969a9`; `test_profiler` `test_overlay_key_release`,
  `test_scene_file` `test_game_config_apply`). `br_debug_log_line` now copies into a caller buffer.
- Profiler fence thread ran in every windowed game (`61524ab`; `test_profiler`
  `test_fence_thread_on_demand`).
- Events: every listener removal walked the whole table (O(n^2) unload); a full hit test per
  mouse-motion event (`229338d`; `test_events` `test_move_coalescing`,
  `test_listener_removal_cost`). Mouse motion is dispatched once per frame.
- Loading saved bindings could leave an action unbound (S3, deferred by the fix agent; fixed in
  the final pass, below).

Open (S3, no commit): the audio mutex is held while streaming voices decode Vorbis on the audio
thread; touch cancel has no event of its own and pointer slots can leak; gamepad capture of an
axis is level-triggered; deterministic runs depend on the host keyboard layout and lock keys.

### R6 3D (merge `7b5d03a`)

Fixed:

- `br_node3d_flush` was not re-entrant (`d53afc1`; `test_three_d` `test_nested_destroy`).
- A glTF scene listing a node twice overflowed `br_model.roots`; accessor counts, offsets and
  URIs were trusted (a 300-byte file overflowed the heap; URIs could leave the asset root)
  (`9e02f27`; new `test_hostile_gltf`).
- Data textures (normal, metallic-roughness, occlusion) were premultiplied; colour textures
  filtered in sRGB space: per-slot colour spaces, `br_model.textures` holds two entries per image
  (`306922c`; `test_gltf` `test_texture_spaces`; `gltf_demo` golden updated, `56c27ad`).
- A skinned mesh kept a pointer into a dead instance's joints (`4b58241`; `test_gltf`
  `test_detached_skin`).
- GPU buffer sizes as wrapping uint32 products (`7cabcee`; `test_three_d`).
- Live-edited material / post-pass counts overflowed at draw (`b3a7035`; no headless test is
  possible, verified with a scratch program that crashed before).
- 3D camera far plane unguarded, 3D shake in stage units (`e516c04`; `test_camera`
  `test_engine_3d`).
- Double-sided back faces flipped n and b but not t (`e6e36dd`; pinned by the
  `backface_normal_demo` golden in the final pass).
- Batched glTF nodes ignored destroy and visibility (`fb77e94`; `test_gltf_scene`); O(n^2)
  insertion sort of draw items (`7a3d32b`; goldens unchanged); stale `br_anim3d.h` and

Open (S3, no commit): a spot light with inner == outer angle gives NaN (`smoothstep` in

### R7 Animation (merge `2f6e38e`, one commit `d2b4d30`)

Fixed: `br_animator_cross_fade` every frame froze the motion; root motion reported a bogus delta

### R8 Whole engine (merge `d5cce2a`, plus R1's lifecycle and save commits)

Fixed: save writes not atomic and the game simulating while minimised (both S2, in R1's
`bf1c65e` / `edc58fc`); save identity; tests that only ran two directories below the source
(now `BRATY_SOURCE_DIR`); a misspelled `--only` passing; skip detection on "cannot claim

Open (S3): fatal start-up errors are only logged (no message box); quit cannot be intercepted;
goldens assert no counts; the API findings ranked as `docs/API_REVIEW.md` items 42-52 (one
duplicate, `br_gpu_set_vsync`, was removed; the pausing item 46 is partly resolved).

## Recommended larger changes (deliberately not made)

Ranked by what they cost a game written today; each was proposed by at least one report.

1. **Remove the duplicate APIs** (R8, API_REVIEW 42): `br_animator3d_*`, `br_orbit_camera_*`,
   `br_ticker_set_max_fps`, `br_color_srgb_to_linear`, `br_engine_random*`. Cheap now; every game
   written against both doubles the migration later.
2. **Wider component field types** (R8, API_REVIEW 43): long text, enums by name, vec4 / quat,
   a 3D node field, fixed-capacity arrays. Strings are 63 bytes today, so a translated sign does
   not fit, and every list-shaped design falls back to hand-parsed cJSON.
3. **Localisation and font fallback** (R8, README "Not implemented yet"): string tables,
   `SDL_GetPreferredLocales`, a fallback chain for glyphs missing from a font (CJK, emoji). Needs
   2 first.
4. **Align the 2D and 3D node APIs** (R8, API_REVIEW 44): position types, child iteration,
   find-by-label rules, layer-bit semantics, counts and destroy hooks; move `br_component3d_*`
   out of `br_gltf.h`. Every agent writing 3D code by analogy with 2D trips over each once.
5. **A headless draw-list test harness** (R6 suggestion 4, R2's render-walk test gap): record
   draw items, instances and joints into CPU arrays at submit so culling, sorting, lights,
   shadow tiles and the 2D render walk can be unit-tested without a GPU. Today only goldens
   catch these.
6. **Asset packaging and title storage** (R8 suggestion 2, API_REVIEW 51): one storage layer
   (title storage for data, user storage for saves, loose files for development), a pack format
   and install rules. Required for consoles and mobile; loose files work on desktop.
7. **A text-field node** (R8): caret, selection, clipboard and IME composition UI on top of
   `br_input_text*`. Every game with a name entry or chat writes one.
8. **A per-node text quad cache** (R4 suggestion 4): keep each text node's glyph quads until its
   text, style or font changes, instead of a cmap lookup per glyph per layer per pass and
   re-emitting all quads every frame. Matters for text-heavy UIs only; no measured problem yet.
